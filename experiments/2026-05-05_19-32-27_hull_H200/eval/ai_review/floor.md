# floor — visual review

The 'floor' region in this run is actually the back-court banner band where the Melbourne wordmark lives — the underlying surface is the vivid blue banner, not the matte court paint, so the canonical Red Bull-on-court halo case does not apply directly. The Red Bull composite sits on near-identical blue with excellent hue match, no visible halo, and only a very faint letter-edge reflex on close inspection. Perspective and scale read correctly within the slanted banner band. Across early/mid/late strips the wordmark is rock-stable temporally — no jitter, no scale wobble. Player feet/legs occlude the wordmark plausibly when they cross it. The main miss is contact-shadow: the player passes over the logo without casting any softening shadow onto it, which slightly weakens the painted-on illusion. Otherwise this is a strong composite — convincingly integrated.
