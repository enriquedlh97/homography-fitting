# floor

A viewer scrubbing the floor logo would see a Red Bull wordmark with the bulls icon sitting flat on the matte court — no halo, no obvious ghost smearing on letter edges, hue matched to the surrounding court blue. Reads as printed-on, not pasted-on. This region's config was not changed in e3, so the result is essentially identical to P3-A33/a2 baseline. The contrast and brightness are calibrated for the court paint, unlike the left banner.
